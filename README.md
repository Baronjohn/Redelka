# Redelka

Initial Godot 4 game project using GDScript.

## Getting started

1. Open this folder in Godot 4.7+.
2. Review design notes in [`game-design/`](game-design/).
3. Run the project from the editor or press F5.

## Project layout

```
Redelka/
├── game-design/     # Game design documents
├── scenes/          # Godot scenes
├── scripts/         # GDScript source
├── assets/          # Art, audio, and other resources
└── project.godot
```
